# Yash Sharma — AI Engineer Portfolio

Responsive single-page portfolio built with React, TypeScript, Vite, and CSS.

## Run locally

```bash
npm install
npm run dev
```

Open the URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

Deploy the `dist/` directory to Vercel, Netlify, or another static host.

## Customize

- Edit content and links in `src/main.tsx`.
- Edit colors, spacing, and layouts in `src/style.css`.
- Replace `public/Yash_Sharma_Resume.pdf` to update the downloadable resume.
- Add a GitHub URL and project demos when ready; these were not available as verified links in the CV.
